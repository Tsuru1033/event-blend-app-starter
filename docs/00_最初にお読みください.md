# 最初にお読みください

このスターターキットは、プログラミング初心者がAIの案内を受けながら、イベント用アプリを導入・公開するためのものです。

詳しい全体説明は、GitHubを開いた最初のファイル一覧にある次のファイルにまとめています。

```text
START_HERE.md
```

まだ`START_HERE.md`を読んでいない場合は、先に開いてください。

---

## 用意するもの

- メールアドレス
- パソコン
- スマートフォン
- GitHubアカウント
- Supabaseアカウント
- Vercelアカウント
- AIサービス
- パスワードを安全に保管できる場所

## 使用するサービス

### GitHub

アプリのプログラム、設定ファイル、説明書を保管します。

### Supabase

参加者の回答、今回の参加人数、集計者のログイン情報を保存します。

### Vercel

GitHubに保存したアプリをインターネット上へ公開します。

各サービスは、アプリを利用する方自身のアカウントで作成してください。

提供元のアカウントを共同利用する必要はありません。

## AIへ最初に送る文章

次の文章をコピーして、使用するAIへ貼り付けてください。

```text
私は、AI、GitHub、Vercel、Supabase、プログラミングの初心者です。

このアプリを導入したいので、最初に次のファイルを確認してください。

- START_HERE.md
- README.md
- AGENTS.md
- AI_HANDOFF.md
- AI_PROMPTS.md
- docs/00_最初にお読みください.md

一度に複数の操作を案内せず、画面のスクリーンショットを送るたびに、次の操作を1つだけ案内してください。

案内するときは、今開く画面、押すボタン、入力する内容、成功したときの表示を明確にしてください。

パスワード、復旧コード、Secret key、service_roleキー、アクセストークンをチャットへ貼るように指示しないでください。
```

---

## 重要な注意

次の情報は、AIとのチャット、GitHub、スクリーンショットへ載せないでください。

- パスワード
- 復旧コード
- GitHubアクセストークン
- Vercelアクセストークン
- SupabaseのSecret key
- service_roleキー
- 管理者UID
- 実際の環境変数
- 個人情報を含む回答データ

Publishable keyはブラウザー用のキーですが、スクリーンショットでは隠すことを推奨します。

提供先ごとに、GitHub、Supabase、Vercelの環境を分けて使用してください。

## 導入完了後に行うこと

アプリを公開しただけでは、導入完了ではありません。

次のファイルを使って、本番前テストを実施してください。

```text
07_本番前テスト.md
```

テスト完了後は、次の状態に戻してください。

```text
回答済み：0
未回答：今回の参加人数
```

この状態を確認してから、本番を開始してください。
