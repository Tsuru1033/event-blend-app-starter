# アカウント作成

## GitHub
1. https://github.com/ を開きます。
2. `Sign up`を押します。
3. メールアドレス、パスワード、ユーザー名を登録します。
4. メール認証を完了します。

## Supabase
1. https://supabase.com/dashboard を開きます。
2. `Continue with GitHub`を選びます。
3. OrganizationとProjectを作成します。
4. Database passwordを安全な場所へ保存します。

## Vercel
1. https://vercel.com/dashboard を開きます。
2. `Continue with GitHub`を選びます。
3. GitHub連携を許可します。

パスワードや秘密キーはAIへ送らないでください。
