# アカウント作成

このアプリでは、次の3つのサービスを使用します。

- GitHub
- Supabase
- Vercel

最初にGitHubアカウントを作成すると、SupabaseとVercelでもGitHubアカウントを使ってログインできます。

---

## 作業前の注意

次の情報は、AIとのチャット、GitHub、スクリーンショットへ載せないでください。

- パスワード
- 2段階認証の6桁コード
- 復旧コード
- GitHubアクセストークン
- Vercelアクセストークン
- SupabaseのSecret key
- service_roleキー

パスワードと復旧コードは、安全に保管できる場所を先に用意してください。

---

## 1. GitHubアカウントを作成する

GitHubは、アプリのプログラム、設定ファイル、説明書を保管するサービスです。

次のページを開きます。

https://github.com/

### 操作手順

1. `Sign up`を押します。
2. メールアドレスを入力します。
3. 安全なパスワードを設定します。
4. ユーザー名を設定します。
5. 画面の案内に従って登録します。
6. GitHubから届いたメールを確認します。
7. メール認証を完了します。

### 登録後に確認すること

- [ ] GitHubへログインできる
- [ ] ユーザー名が表示される
- [ ] 登録メールアドレスを確認できる
- [ ] パスワードを安全な場所へ保存した

---

## 2. Supabaseアカウントを作成する

Supabaseは、参加者の回答、今回の参加人数、集計者のログイン情報を保存するサービスです。

次のページを開きます。

https://supabase.com/dashboard

### 操作手順

1. ログインまたは登録画面を開きます。
2. `Continue with GitHub`を選びます。
3. GitHubとの連携画面が表示された場合は、内容を確認して許可します。
4. Supabaseの管理画面が表示されることを確認します。

### この段階ではプロジェクトを作らなくても大丈夫です

Supabaseプロジェクトの名前、リージョン、データベースパスワードは、次のガイドで一つずつ設定します。

```text
03_Supabase設定.md
```

すでにプロジェクト作成画面まで進んだ場合も問題ありません。画面を閉じず、AIへスクリーンショットを送り、次の操作を確認してください。

### 登録後に確認すること

- [ ] Supabaseの管理画面を開ける
- [ ] GitHubアカウントと連携できた
- [ ] 自分のOrganizationが表示される

---

## 3. Vercelアカウントを作成する

Vercelは、GitHubに保存したアプリをインターネット上へ公開するサービスです。

次のページを開きます。

https://vercel.com/dashboard

### 操作手順

1. ログインまたは登録画面を開きます。
2. `Continue with GitHub`を選びます。
3. GitHubとの連携画面が表示された場合は、内容を確認して許可します。
4. Vercelの管理画面が表示されることを確認します。

### GitHubのアプリが表示されない場合

後の公開作業で、Vercelに使用を許可するGitHubのアプリを追加できます。

```text
Adjust GitHub App Permissions
```

詳しい操作は次のガイドで確認します。

```text
04_Vercel公開.md
```

---

## 4. Vercelの2段階認証を設定する

Vercelから2段階認証の設定を求められた場合は、認証アプリを使用することを推奨します。

使用できる認証アプリの例です。

- Microsoft Authenticator
- Google Authenticator

### 認証アプリを使う場合

1. Vercelで`Set Up Authenticator App`を押します。
2. スマートフォンで認証アプリを開きます。
3. 認証アプリでVercel画面のQRコードを読み取ります。
4. 認証アプリに表示された6桁コードをVercelへ入力します。
5. 設定完了後に復旧コードを保存します。

### 重要

次の情報は、AIとのチャットやスクリーンショットへ載せないでください。

- 認証設定用QRコード
- 6桁の認証コード
- 復旧コード

復旧コードは、スマートフォンや認証アプリを利用できなくなった場合に使います。

パスワード管理アプリなど、安全な場所へ保存してください。

復旧コードがスクリーンショットへ写った場合は、Vercelの認証設定から新しい復旧コードを再生成し、古いコードを無効にしてください。

## 5. ブラウザーのタブを整理する

導入中は、次の画面を複数のタブで開くことがあります。

- GitHub
- Supabase
- Vercel
- 公開したアプリ
- AIとのチャット

操作前に、現在どのサービスを開いているか確認してください。

本番用とテスト用の両方を作成した場合は、プロジェクト名も確認してください。

間違った環境を変更しないよう、AIへスクリーンショットを送るときは、画面上部のサービス名やプロジェクト名が分かる範囲を含めてください。

秘密情報が表示されている部分は隠してください。

## よくある問題

### GitHubから確認メールが届かない

- 迷惑メールフォルダーを確認する
- 入力したメールアドレスを確認する
- 少し待ってから再送する

### SupabaseやVercelへGitHubでログインできない

- GitHubへログイン済みか確認する
- 別のGitHubアカウントを開いていないか確認する
- ブラウザーのポップアップが遮断されていないか確認する

### Vercelで6桁コードを求められた

Microsoft Authenticatorなどの認証アプリを開き、Vercelの項目に表示される最新の6桁コードを入力します。

6桁コードは一定時間で変わるため、古いコードは使用できません。

### パスワードが分からなくなった

各サービスのパスワード再設定機能を使用してください。

AIへパスワードそのものを送らないでください。
