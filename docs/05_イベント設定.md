# イベント設定

このアプリでは、設定内容によって変更する場所が異なります。

- 今回の参加人数：アプリの集計者画面から変更
- イベント名、商品名、配合量：GitHubの設定ファイルから変更

---

## 今回の参加人数を変更する

このアプリは、最大30名まで対応しています。

実際に参加する人数は、コードを編集せず、アプリの集計者画面から設定できます。

### 操作手順

アプリを開き、次の順に進んでください。

```text
集計者
→ メールアドレスとパスワードでログイン
→ イベント設定
→ 今回の参加人数を入力
→ 参加人数を保存
```

設定できる人数は、1名から30名までです。

### 20名に設定した場合

次の内容が自動的に変わります。

- 全札数が20になる
- 未回答番号が1～20になる
- 札番号入力欄が1～20になる
- 札番号20の固有QRが有効になる
- 札番号21以降は対象外になる
- 主催者番号が20番になる
- ランキングやマッチは1～20番の回答を対象にする

### 保存できたときの表示

次のようなメッセージが表示されます。

```text
参加人数を20名に設定しました。主催者番号も20番です。
```

保存後にページを再読み込みし、参加人数が維持されていることを確認してください。

参加人数はSupabaseへ保存されるため、別の端末から開いた場合も同じ人数が反映されます。

---

## 参加人数を減らす場合の注意

参加人数を減らしたとき、対象外になる札番号に回答がある場合は、確認メッセージが表示されます。

例として、30名から20名へ変更したときに、札番号21～30の回答が残っている場合が該当します。

対象外になった回答は、自動では削除されません。

ただし、次の集計には含まれなくなります。

- 回答済み数
- 人気ベース
- 人気フレーバー
- 3種類マッチ
- 完全一致
- 発表モード

不要な回答を完全に消す場合は、集計者画面の「全回答を削除」を使用してください。

「全回答を削除」は、対象外の回答だけでなく、保存されている回答をすべて削除します。必要な回答が残っている場合は実行しないでください。

---

## イベント名や商品名を変更する

イベント名、商品名、配合量などの基本設定は、GitHubの次のファイルにまとめられています。

```text
src/config/eventConfig.js
```

変更方法が分からない場合は、`eventConfig.js`をAIへ確認してもらい、完成版ファイルを作成してもらってください。

### 変更できる主な項目

- イベント名
- 初期参加人数
- 商品名
- ベース量
- 合計量
- 選択できる配合量

---

## イベント名を変更する

次の項目を変更します。

```javascript
eventName: '日本酒 試飲＆ブレンド体験',
```

引用符の内側だけを、新しいイベント名へ変更してください。

例：

```javascript
eventName: 'オリジナルブレンド体験会',
```

---

## 商品名を変更する

商品は、番号と名称の組み合わせで設定されています。

```javascript
items: [
  { id: 1, name: '商品名1' },
  { id: 2, name: '商品名2' },
  { id: 3, name: '商品名3' },
]
```

### 変更時の注意

- `id`は重複させない
- 番号は原則として1から順番にする
- 商品名は引用符の内側だけを変更する
- カンマを削除しない
- 波括弧や角括弧を削除しない
- 回答データには商品名ではなく商品番号が保存される

イベント開始後に商品番号と商品名の対応を変更すると、過去の回答表示も新しい商品名へ変わります。

本番回答が入った後は、番号の並びを変更しないでください。

---

## 配合量を変更する

主な配合設定は次の項目です。

```javascript
baseAmount: 20,
totalAmount: 40,
flavorAmounts: [5, 10, 15],
```

それぞれの意味は次のとおりです。

- `baseAmount`：ベースの固定量
- `totalAmount`：完成後の合計量
- `flavorAmounts`：フレーバー1で選択できる量

配合量を変更すると、フレーバー2の量は合計量から自動計算されます。

### 変更時の注意

選択可能なすべての組み合わせで、フレーバー2の量が正常な値になることを確認してください。

変更後は、実際に回答画面を開き、次を確認します。

- 合計量が正しい
- フレーバー2が正しく自動計算される
- 回答を保存できる
- 回答済み画面の配合量が正しい
- 完全一致の判定が正しい

---

## 初期参加人数について

`eventConfig.js`には、初期参加人数の設定があります。

```javascript
totalTickets: 30,
```

この値は、Supabaseからイベント設定を取得できない場合や、新しい環境で最初に表示する人数の基準です。

実際のイベント運用中は、集計者画面から保存した参加人数が優先されます。

通常のイベントでは、この数字を毎回GitHubで変更する必要はありません。

---

## 設定変更後の反映方法

GitHubで`eventConfig.js`を変更した場合は、変更内容を保存してください。

GitHubとVercelが接続されていれば、Vercelで新しい公開処理が自動的に始まります。

Vercelの状態が次になるまで待ってください。

```text
Ready
```

その後、公開アプリを再読み込みして変更を確認します。

古い表示が残る場合は、ブラウザーを強制再読み込みしてください。

Windowsの場合：

```text
Ctrl + Shift + R
```

---

## AIへ変更を依頼する場合

AIへ次のように依頼してください。

```text
私はプログラミング初心者です。

src/config/eventConfig.jsを確認し、イベント名、商品名、配合量を変更してください。

既存の回答、回答修正、ランキング、3種類マッチ、完全一致、発表モードを壊さないでください。

変更前に影響範囲を説明し、変更後は完成版ファイルを生成してください。
```

参加人数だけを変更する場合は、AIへコード変更を依頼せず、集計者画面から設定してください。

---

## 変更後の確認項目

### 参加人数を変更した場合

- 集計者画面に設定した人数が表示される
- 再読み込み後も人数が維持される
- 最後の有効な札番号が使用できる
- 次の札番号が対象外になる
- 未回答番号が正しい
- 主催者番号が参加人数と同じになる

### イベント名や商品名を変更した場合

- 画面上部のイベント名が正しい
- 商品番号と商品名の対応が正しい
- 参加者画面の選択肢が正しい
- 集計者画面の商品名が正しい
- 発表モードの商品名が正しい

### 配合量を変更した場合

- 合計量が正しい
- 自動計算される量が正しい
- 回答を保存できる
- 回答を修正できる
- 完全一致が正しく判定される

設定変更後は、テスト回答を使って主要機能を確認し、本番開始前にテスト回答を削除してください。
